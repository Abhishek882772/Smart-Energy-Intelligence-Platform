# Machine Learning Research Workspace

This directory contains the Machine Learning (ML) and research work for the Smart Energy Intelligence Platform. It is intentionally separate from the application's frontend and backend so that research experiments can evolve without disturbing product code.

## Research objective

The research topic is **Cross-Country Generalization and Data-Efficient Adaptation of NILM Models for Indian Residential Energy Consumption**.

NILM (Non-Intrusive Load Monitoring) estimates the energy use of individual appliances from a home's whole-house electricity signal. The research will study how well a model trained on international residential data transfers to Indian residential data, and how much Indian data is needed to adapt it effectively.

## Planned pipeline

The complete pipeline is planned for a later milestone:

1. Select an international residential electricity dataset.
2. Preprocess and document the data.
3. Train a NILM model using international training data.
4. Evaluate it on held-out international data.
5. Perform zero-shot evaluation on Indian test data.
6. Adapt/fine-tune with 1%, 5%, 10%, and 20% Indian data.
7. Evaluate each adaptation setting.
8. Analyse and report cross-country generalization and data efficiency.

This initial milestone only establishes the workspace and a Python environment check. No dataset, model, neural network, or research result is included yet.

## Environment setup

From the repository root, create and activate a virtual environment:

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r ML\requirements.txt
python ML\src\environment_check.py
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r ML/requirements.txt
python ML/src/environment_check.py
```

The initial dependency file is intentionally empty of third-party packages because the sanity check uses only Python's standard library. Dependencies will be added, pinned, and explained when preprocessing and modelling begin.

## Collaboration rules

- Keep ML changes on the `ML` branch.
- Do not commit downloaded datasets, secrets, virtual environments, cache files, or model checkpoints.
- Record the dataset version, preprocessing choices, random seeds, and evaluation settings when experiments are introduced.
- Keep generated results reproducible and distinguish exploratory notebooks from reusable source code.
